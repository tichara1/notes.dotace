# Financování: přímá dotace vs bezúročný úvěr

Od 2026 je pro běžné žadatele místo přímé dotace **bezúročný úvěr**
(100 tis.–2 mil. Kč, úroky hradí fond). NZÚ Light = přímá dotace.

## Srovnání variant

| Kritérium | Přímá dotace (NZÚ Light) | Bezúročný úvěr |
|-----------|--------------------------|----------------|
| Kdo má nárok |  |  |
| Kolik získáme |  |  |
| Kdy přijdou peníze |  | až po Rozhodnutí ministra; jednorázově nebo postupně **dle banky a smlouvy** (najednou dopředu není zaručené — [ověření](../07-specialiste/consultora-overeni.html)) |
| Co splácíme |  |  |
| Banka / poskytovatel |  | zatím nevybráno; Consultora nabízí propojení s poradcem banky |
| Klady |  |  |
| Zápory |  |  |

## Naše čísla
- Odhad celkových nákladů: _viz [Rozpočet](../09-rozpocet/rozpocet.html)_
- Služby Consultory: 90 000 Kč (Fáze 0–4) + 20 000 Kč (TDI); z úvěru jde **~80 000 Kč**
  (projekt + EH + TDI), Fáze 3 + 4 (20 000 Kč) ne, Fáze 0 nejasně →
  [ověření](../07-specialiste/consultora-overeni.html)
- Kolik pokryje dotace/úvěr:
- Vlastní zdroje potřebné:
- Měsíční dopad (splátka + energie): _viz [Měsíční platby](../05-model/mesicni-naklady.html)_

## Rozhodnutí
**Bezúročný úvěr, oblast komplexní** (na přímou dotaci NZÚ Light nemáme nárok — viz
[Rešerše](../reserse-nzu-2026.html)). Žádost a doložení vyřizuje
[Consultora](../07-specialiste/consultora.html); s Kladným rozhodnutím ministra pak
žádáme o úvěr v bance / spořitelně.

> _Bonita: loňské předschválení (jiný produkt, před změnou podmínek) **nemá právní
> účinek** — banka bonitu posoudí znovu až s Rozhodnutím ministra._
