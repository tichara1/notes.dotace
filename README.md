# Rekonstrukce domu + dotace NZÚ 2026+

Poznámky a plánování rekonstrukce rodinného domu s dotací **Nová zelená
úsporám 2026+** (vyhlášena 28.5.2026). Repo se publikuje jako GitHub Pages.

## Jak to používat

- Píšeš do `.md` souborů ve složkách `01-` až `10-`. Každá složka má `index.md`,
  který říká, co do ní patří; stránky mají kostru (nadpisy, checklisty, tabulky).
- **Podklady** (dům, energie, opatření) zapisuj jako čísla do tabulek — AI z nich
  počítá [model úspor](05-model/), vybírá firmy a materiály.
- Hotovou položku v checklistu odškrtni: `- [x]`.
- 🔒 Web je **veřejný**: skeny, vyúčtování a fotky s osobními údaji dávej jen do
  lokální složky `_soukrome/` (je v `.gitignore`), do repa jen čísla a závěry.

## Obsah

1. [Přehled](01-prehled/) — cíl, rozsah, harmonogram
2. [Dům](02-dum/) — podklady o domě (plochy, konstrukce, okna, technika)
3. [Energie](03-energie/) — vyúčtování elektřiny a plynu
4. [Opatření](04-opatreni/) — navržená opatření, varianty, materiály
5. [Model úspor](05-model/) — předpoklady, úspory, návratnost, měsíční platby
6. [Dotace](06-dotace/) — NZÚ 2026+, podklady, financování
7. [Specialisté](07-specialiste/) — energetický specialista, spolupráce s Consultorou
8. [Realizace](08-realizace/) — firmy podle recenzí, poptávky, nabídky
9. [Rozpočet](09-rozpocet/) — náklady, dotace/úvěr, vlastní zdroje
10. [Dokumenty](10-dokumenty/) — deník jednání a dokumenty

Neaktuální poptávky a poznámky jsou v [Archivu](archiv/) — nic se nemaže, jen přesouvá.
