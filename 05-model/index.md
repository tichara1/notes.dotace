# Model úspor a návratnosti

**Co sem patří:** výpočty, kolik opatření ušetří a za jak dlouho se vrátí —
předpoklady, výsledky po opatřeních i po variantách a dopad na měsíční rozpočet.
Model se počítá (s pomocí AI) z podkladů v ostatních sekcích:

| Vstup | Odkud |
|-------|-------|
| Dům — plochy, konstrukce, otvory | [Dům](../02-dum/index.html) |
| Skutečná spotřeba a ceny energií | [Energie](../03-energie/index.html) |
| Navržená opatření a parametry | [Opatření](../04-opatreni/index.html) |
| Náklady a výše úvěru | [Rozpočet](../09-rozpocet/rozpocet.html), [Dotace](../06-dotace/index.html) |

- [Předpoklady modelu](predpoklady.html) — ceny energií, růst cen, výroba FVE, splatnost
- [Úspory a návratnost](navratnost.html) — výsledky po opatřeních a variantách
- [Měsíční platby: teď vs. po rekonstrukci](mesicni-naklady.html) — dosavadní orientační propočet

## Jak s modelem pracovat

1. Doplň vstupy (hlavně [vyúčtování](../03-energie/vyuctovani.html) a po Fázi 0
   [varianty](../04-opatreni/varianty.html)).
2. Zkontroluj [předpoklady](predpoklady.html) — každý má zdroj a nejistotu.
3. Požádej AI o přepočet: _„Přepočítej Model úspor podle aktuálních podkladů
   v 02–04 a předpokladů, uveď nejistoty."_
4. Výsledek zapiš do [Úspory a návratnost](navratnost.html) s datem výpočtu.

> Všechny výsledky jsou **odhad**. U každého čísla musí být jasné, z jakých
> předpokladů vychází.
